# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform (GCP) is a cloud computing platform that provides infrastructure, storage, databases, networking, data analytics, artificial intelligence, and application development services.

## Global Infrastructure

Google Cloud uses a global infrastructure organized into regions and zones. This infrastructure enables organizations to deploy applications in different geographic locations and improve availability, performance, and reliability.

## Cloud Management Console

The Google Cloud Console is a web-based interface used to create, configure, monitor, and manage Google Cloud resources and services.

## Four Core Services

1. **Compute Engine** – Provides virtual machines for running applications.
2. **Cloud Storage** – Provides scalable object storage.
3. **Cloud SQL** – Provides managed relational databases.
4. **Cloud Functions** – Provides serverless execution for application code.

## Three Advantages

1. **Strong Data and Analytics Tools** – Provides powerful services for processing and analyzing data.
2. **Global Infrastructure** – Uses Google's worldwide infrastructure to support applications.
3. **AI and Machine Learning** – Provides services and tools for developing AI and machine learning applications.

## Typical Enterprise Use Cases

GCP is commonly used for data analytics, artificial intelligence and machine learning, application hosting, database management, large-scale data processing, storage, and cloud-native application development.
