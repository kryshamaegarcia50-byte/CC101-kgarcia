# Cloud Platform Recommendation Challenge

## Client A – Startup Company

**Recommended Platform: Google Cloud Platform (GCP)**

Google Cloud Platform is a good choice for the startup because it offers scalable services that can support the company's growth while allowing the company to start with manageable resources. Its serverless and managed services can reduce the need for the startup to maintain physical servers. GCP also provides tools for application development, storage, and databases that can support a growing mobile application. The startup can increase its resources as the number of users grows.

**Recommended Services:**
- Google Cloud Run – for deploying and running the mobile application's backend.
- Cloud Storage – for storing application files and data.
- Cloud SQL – for the application's relational database.

## Client B – University

**Recommended Platform: Microsoft Azure**

Microsoft Azure is the most appropriate choice for the university because it already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's existing technologies, making the migration process easier and more familiar for the university's IT staff. The university can also use Azure to extend its existing infrastructure into the cloud while maintaining identity and access management. This makes Azure a practical option for a hybrid cloud environment.

**Recommended Services:**
- Azure Virtual Machines – for running Windows-based workloads.
- Microsoft Entra ID – for identity and access management.
- Azure SQL Database – for managed relational databases.

## Client C – AI Research Company

**Recommended Platform: Google Cloud Platform (GCP)**

Google Cloud Platform is recommended because the company focuses on Artificial Intelligence and Machine Learning applications. GCP provides specialized AI and machine learning tools as well as high-performance computing resources that can support research workloads. Its infrastructure can be used to train and deploy machine learning models at scale. These capabilities make GCP suitable for an AI-focused research organization.

**Recommended Services:**
- Vertex AI – for developing, training, and deploying machine learning models.
- Compute Engine – for high-performance computing workloads.
- Cloud Storage – for storing large datasets and research files.

---

## Client D – Global E-Commerce Company

**Recommended Platform: Amazon Web Services (AWS)**

AWS is a strong choice for a multinational e-commerce company because it provides global infrastructure and services designed for highly available and scalable applications. The company can deploy its application across multiple Availability Zones and geographic Regions to improve reliability. AWS also provides automatic scaling and load balancing services that can respond to changes in customer traffic. This makes AWS suitable for an online shopping platform serving customers around the world.

**Recommended Services:**
- Amazon EC2 – for running application servers.
- Elastic Load Balancing – for distributing traffic across servers.
- Amazon EC2 Auto Scaling – for automatically adjusting computing capacity based on demand.
