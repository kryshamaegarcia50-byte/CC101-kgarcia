# Laboratory 03 - Multi-Cloud Explorer

## Overview

This laboratory explores and compares major cloud computing platforms, including Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).

## Objectives

- Research AWS, Azure, and GCP.
- Compare the features and services of different cloud platforms.
- Identify the most suitable cloud platform for different client needs.
- Provide recommendations based on the comparison.
