## Questions and Answers

### 1. Which cloud provider offers the broadest range of services?

AWS offers one of the broadest ranges of cloud services among the three major providers. It provides services for computing, storage, databases, networking, security, analytics, artificial intelligence, and many other areas.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure best integrates with Microsoft technologies. It works closely with products and services such as Windows Server, Microsoft 365, Active Directory, and other Microsoft enterprise solutions.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is particularly strong in Artificial Intelligence, machine learning, and Kubernetes. Google also created Kubernetes, making GCP a strong choice for organizations developing modern cloud-native and containerized applications.

### 4. Which cloud platform would you personally choose and why?

I would personally choose Google Cloud Platform because of its strong tools for artificial intelligence, data analytics, and Kubernetes. I also think its services are useful for developing modern applications and learning cloud technologies.
