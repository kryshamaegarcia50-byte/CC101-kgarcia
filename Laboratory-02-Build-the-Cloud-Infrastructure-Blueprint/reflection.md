# Mission Reflection

This mission helped me understand more about how cloud infrastructure works and how important each part of a system is. Before doing the activity, I mostly thought of cloud computing as just using servers online. After working with the Linux server, I realized that there are several components working together to make everything function properly.

For me, the **compute component** is the most important because it is responsible for actually running programs and processes. In our Linux server, we worked with a virtualized CPU, which showed me how computing resources can be provided through virtualization. Without enough computing resources, the other parts of the infrastructure would not be able to perform their tasks properly.

Linux supports cloud computing by providing a reliable environment where servers, applications, storage, and networking can be managed. During the activity, I used different Linux commands to check the operating system, CPU, memory, storage, and network configuration. This made it easier for me to understand what is happening inside a cloud server instead of just looking at it as a black box.

Technical documentation is also important before deploying infrastructure because it gives you a clear record of what needs to be configured and how everything is connected. It can also make troubleshooting easier because you can go back and check the settings and commands that were used.

One new skill I developed during this laboratory was using Linux commands to inspect a server's infrastructure. I learned how to check system information, storage, memory, and network settings using commands such as `lscpu`, `free -h`, `df -h`, `lsblk`, and `ip addr`.

After completing this mission, my GitHub repository became more useful because it now contains my laboratory files, documentation, and infrastructure information. It also helped me practice keeping my technical work organized and properly documented.
