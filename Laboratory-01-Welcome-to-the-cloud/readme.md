# Laboratory 01 - Welcome to the Cloud

## Mission Overview

This laboratory activity represents the onboarding experience of a Junior Cloud Infrastructure Engineer Trainee at CloudNova Technologies. The activity focuses on setting up and working with a cloud-based Linux environment through KillerCoda, examining the system, managing files and folders, and recording the completed tasks in a GitHub repository.

## Objectives

* Access and use a cloud-based Linux environment through KillerCoda
* Become familiar with navigating and using the Linux operating system
* Collect and examine basic information about the system
* Create and manage files and directories using Linux commands
* Set up and maintain a properly organized GitHub repository
* Record technical activities and results using Markdown documentation

## Activities Performed

1. Started an Ubuntu 24.04 environment using KillerCoda
2. Added a new user account (kgarcia), provided sudo privileges, and accessed the account
3. Checked important system details, including the Linux distribution, kernel, CPU, memory, and available disk space
4. Built a directory structure containing Documents, Notes, Reports, and Screenshots, along with an about-me.md file
5. Created a public GitHub repository and arranged its contents based on the required structure
6. Recorded the completed mission and collected screenshots as supporting evidence
7. Saved the changes through Git commits and uploaded the completed work to GitHub

## Linux Commands Used

* `sudo adduser`, `usermod -aG sudo`, `su`
* `whoami`, `pwd`, `hostname`
* `cat /etc/os-release`, `uname -r`, `lscpu`, `free -h`, `df -h`
* `mkdir`, `touch`, `nano`, `ls`, `cat`
* `git clone`, `git add`, `git commit`, `git push`

## Skills Learned

* Creating and managing Linux users and their permissions
* Navigating the Linux system and checking system information
* Properly arranging files and directories
* Creating technical documentation with Markdown
* Working with Git and GitHub for version control and building a professional portfolio
