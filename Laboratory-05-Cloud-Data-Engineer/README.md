# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This mission focused on understanding cloud storage and deploying MinIO as an object storage server using Docker.

## Objectives

- Understand different types of cloud storage.
- Deploy a MinIO object storage server.
- Access the MinIO Web Console.
- Create an object storage bucket.
- Upload a sample file to the bucket.
- Document the deployment process.

## Tools Used

- KillerCoda
- Ubuntu 24.04
- Docker
- MinIO
- GitHub
- Web Browser

## Skills Learned

- Cloud storage concepts
- Docker container deployment
- MinIO object storage management
- Creating and managing storage buckets
- Uploading objects to cloud storage
- Technical documentation
- Git and GitHub
