# Laboratory 09: Cloud Automation Engineer

## Mission Overview
This laboratory explores cloud automation and backup scripting to help cloud engineers perform repetitive tasks efficiently.

## Objectives
- Understand cloud automation.
- Research automation tools.
- Learn backup scripting fundamentals.
- Practice Git and GitHub version control.

## Tools Used
- Ubuntu Linux
- KillerCoda
- Bash scripting
- Git and GitHub

## Skills Learned
- Cloud automation concepts
- Linux command-line operations
- Backup scripting
- Documentation and version control
