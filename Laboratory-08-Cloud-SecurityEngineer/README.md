# Laboratory 08: Cloud Security Engineer

## Mission Overview
This laboratory focuses on cloud security, security auditing, and firewall configuration.

## Objectives
- Identify common security risks.
- Inspect basic Linux security information.
- Understand firewall rules and network security.
- Document security audit findings.
- Apply basic security best practices.

## Tools Used
- KillerCoda
- Ubuntu Linux
- Git and GitHub
- Linux security commands

## Skills Learned
- Basic security auditing
- Linux command-line operations
- Firewall configuration concepts
- Security documentation
- Git version control
