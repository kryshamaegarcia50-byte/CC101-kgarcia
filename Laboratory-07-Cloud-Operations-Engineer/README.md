# Laboratory 07: Cloud Operations Engineer

## Mission Overview
This laboratory focuses on cloud operations, system monitoring, and container observability. It helps develop practical skills in checking system resources and monitoring containerized applications.

## Objectives
- Collect system baseline information.
- Understand container observability and monitoring.
- Document laboratory activities and results.
- Practice using Linux commands and GitHub for cloud operations.

- Ubuntu Linux
- Git and GitHub
- Docker, if available

## Skills Learned
- Linux system monitoring
- System resource analysis
- Container observability
- Technical documentation
- Version control using Git and GitHub
